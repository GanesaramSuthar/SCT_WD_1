# SCT_WD_1 — Responsive Landing Page

A modern and responsive landing page developed as **Task 1** of my Web Development Internship at **SkillCraft Technology**.

## 🚀 About the Project

This project focuses on building a responsive landing page using fundamental web development technologies. It demonstrates the implementation of a clean user interface, structured HTML, and CSS styling.

## ✨ Features

- Responsive landing page design
- Clean and user-friendly interface
- HTML5 for page structure
- CSS3 for styling and layout
- Organized and maintainable code
- Works on modern web browsers

## 🛠️ Technologies Used

- **HTML5** — Structure and content
- **CSS3** — Styling and layout

## 📂 Project Structure

```text
SCT_WD_1/

```

## 💻 How to Run the Project

1. Clone this repository:

   ```bash
   git clone https://github.com/GanesaramSuthar/SCT_WD_1.git
   ```

2. Open the project folder:

   ```bash
   cd SCT_WD_1
   ```

3. Open `index.html` in your web browser.

You can also open the project directly in Visual Studio Code and use the Live Server extension.
